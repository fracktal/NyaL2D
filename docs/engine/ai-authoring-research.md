# AI로 2D 퍼펫 만들기: 관련 연구 (2026-11-03)

"그림 한 장 → 움직이는 2D 퍼펫"을 자동화하는 연구를 정리했다. 각 항목은 공개 논문 페이지·프로젝트 페이지 기준이고, 코드는 실행해 보지 않았다.
Live2D 매뉴얼에서 "저작 도구 자동화"(얼굴 각도 자동 생성, 모션 자동 생성 등)라고 부른 영역이 여기에 해당한다([live2d-feature-map.md](live2d-feature-map.md) 3절).

## 한눈에

| 연구 | 하는 일 | 공개 상태 | 우리에게 |
| --- | --- | --- | --- |
| **See-through** (SIGGRAPH 2026) | 애니 그림 1장 → 부위별 레이어 최대 약 23장(PSD) + 깊이, 가려진 부분까지 채움 | 코드 Apache-2.0, 모델 가중치 라이선스는 각 모델 페이지 확인 필요 | **가장 바로 쓸 만함.** 파이프라인의 첫 단계(그림 쪼개기) |
| **Bunraku** (arXiv 2026-07) | 그림 1장 → 레이어 + 레이어별 메시 + 파라미터별 꼭짓점 이동량 예측 → 고개 돌리기·끄덕이기·시선 | 코드 GitHub 공개, 라이선스 미표기, 상용은 이메일 문의 | **우리 목표와 가장 가까움.** 출력 구조(파라미터마다 꼭짓점 이동량을 더함)가 우리 엔진의 블렌드 셰이프와 같은 모양 |
| **CartoonAlive** (arXiv 2025-07) | 인물 사진/초상화 1장 → Live2D 모델, 30초 이내. 3D 얼굴 모델의 표정 기저를 2D에 적용 | 프로젝트 페이지만, 코드 공개 확인 못 함 | 표정(얼굴) 자동 리깅 방법 참고 |
| **Textoon** (arXiv 2025-01) | 글 설명 → Live2D 캐릭터, 1분 이내. 미리 만든 부위 템플릿(머리·상의·치마 등)에 그림을 생성해 채움. 음성 → 입 모양 | 프로젝트 페이지만, 코드 공개 언급 없음 | "리그 템플릿 + 그림 생성" 방식 참고 |
| **Talking Head Anime** (Khungurn, 2019~) | 애니 얼굴 이미지 1장을 신경망이 직접 다시 그려서 움직임 | 코드 공개 | 메시 없이 신경망으로 그리는 다른 접근. 실시간 GPU 필요, 편집은 어려움 |
| **Animated Drawings** (Meta, 2023) | 아이 그림 → 뼈대 자동 추정 → ARAP 변형으로 걷기·춤 | 코드 공개 (MIT로 알고 있음, 재확인 필요) | 뼈대 자동 추정 + 핀 기반 변형 참고 |
| **ARAP** (Igarashi 외, 2005) | 핀 몇 개로 그림을 자연스럽게 휘기 | 고전 논문 | AI 편집 명령("팔을 들어")을 메시 변형으로 바꾸는 기본기 |

## 각 연구에서 알게 된 것

### See-through
- 출력: 앞머리, 뒷머리, 얼굴, 눈 부위, 옷, 장신구 등 의미 단위 레이어 PSD + 레이어별 깊이 이미지.
- 저자 스스로 "아직 이미지→Live2D는 아니다. 리깅·메시·모션은 다루지 않는다"고 밝힘. 즉 **그림 쪼개기 담당**.
- 사용 후기(제3자): 큰 GPU(테스트는 96GB)에서 약 2분. 옆 포니테일처럼 분류에 없는 부위는 다른 부위에 합쳐짐, 신발 누락 사례, 손이 얼굴을 가리거나 극단적 원근은 약함. 입을 살짝 벌린 그림이 입 리깅에 유리.
- 우리 쓰임: PSD 가져오기 앞단에 "레이어 없는 그림도 받기" 기능으로 붙일 수 있다. 무거운 모델이라 사용자 PC나 클라우드 GPU에서 따로 돌리는 구조가 맞다.

### Bunraku
- 1단계: 순서 있는 RGBA 레이어 스택 예측(사람 부위 분류에 묶이지 않아 가방·치마 조각도 레이어가 됨).
- 2단계: 레이어 알파에서 삼각형 메시 생성 → 한 번의 계산으로 모든 꼭짓점의 파라미터별 이동량 예측.
- 여러 파라미터는 이동량을 더해서 합성. 4개 동시 구동은 괜찮았고 6개에서는 레이어가 벌어짐(→ 우리 엔진의 글루·디포머 계층이 보완할 지점).
- 물리는 다루지 않음.
- 우리 쓰임: 엔진 5단계의 **블렌드 셰이프**가 있으면 이런 모델의 출력을 그대로 담을 수 있다. 엔진 형식을 정할 때 "AI가 예측한 꼭짓점 이동량을 넣을 자리"를 염두에 둔다.

### CartoonAlive / Textoon
- 둘 다 같은 연구 그룹 계열로 보이며, 결과를 실제 Live2D 형식으로 낸다. 코드 공개는 확인하지 못했다.
- 공통 아이디어: **미리 잘 만든 리그 템플릿**에 새 그림을 맞춰 넣는다. 처음부터 리그를 예측하는 것보다 안정적이다.

## 우리 프로젝트에 주는 시사점

1. **자동 생성 파이프라인의 현실적인 모양**
   그림 1장 → (See-through류) 부위 레이어 → 메시 자동 생성 → (템플릿 맞추기 또는 Bunraku류 예측) 파라미터별 변형 → 물리 자동 설정 → 사람이나 AI가 대화로 다듬기.
2. **엔진 형식에 미리 넣을 것**
   - 블렌드 셰이프(파라미터별 꼭짓점 이동량 가산): AI 예측 결과를 담는 그릇. 원래 5단계였는데 2~3단계로 당기는 것을 검토.
   - 레이어별 깊이 값: See-through가 주는 깊이를 저장해 두면 고개 돌릴 때 시차(앞머리가 얼굴보다 많이 움직이는 것)를 자동 계산할 수 있다.
   - 의미 태그(`hair.front` 등): 이미 아키텍처 문서에 있음. 자동 생성기와 AI 편집이 같은 이름을 쓰게.
3. **아직 아무도 잘 못 하는 것** (우리의 차별점 후보)
   - 물리 자동 설정(머리카락·치마 흔들림).
   - 파라미터 여러 개를 동시에 돌려도 레이어가 안 벌어지는 안정성.
   - 자동 생성 결과를 **대화로 고치는** 편집 루프. 위 연구들은 모두 "한 번에 생성"에서 끝난다.
4. **주의**
   - 이 모델들은 큰 GPU가 필요해서 브라우저 안에서는 못 돌린다. 엔진과는 별개의 "생성 서버" 부품으로 둔다.
   - 가중치·데이터 라이선스가 코드 라이선스와 다를 수 있다. 쓰기 전에 각 모델 페이지를 확인한다.
