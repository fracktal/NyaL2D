# Live2D 기능 목록과 우리 엔진 대응표

Live2D Cubism 공식 공개 설명서(에디터 매뉴얼의 목차·용어집)를 기준으로 "무엇을 할 수 있는 도구인가"만 정리했다. 코드나 비공개 파일 형식은 보지 않았다.
"단계"는 [roadmap.md](roadmap.md)의 단계 번호, "층"은 그 기능이 들어갈 곳이다.

- **코어**: 엔진 계산 (Rust)
- **렌더러**: 화면에 그리기
- **애니메이션**: 파라미터 값을 쓰는 상위 모듈
- **저작 도구**: 편집 앱·AI 편집 기능 (엔진 위)

출처: [에디터 매뉴얼 목차](https://docs.live2d.com/en/cubism-editor-manual/top/), [용어집](https://docs.live2d.com/en/cubism-editor-manual/glossary/), [디포머](https://docs.live2d.com/en/cubism-editor-manual/deformer/)

## 1. 모델 구조 (런타임이 꼭 지원해야 하는 것)

| Live2D 기능 | 무엇인가 | 우리 엔진 | 단계 | 층 |
| --- | --- | --- | --- | --- |
| 아트메시 | 텍스처 조각 + 삼각형 그물 | Mesh 노드 | 1 | 코어+렌더러 |
| 아트패스 | 선(스트로크)을 메시처럼 움직이는 것 | 후순위. 처음엔 메시로 대체 | 8 이후 | 코어+렌더러 |
| 파트 | 부위 묶음, 불투명도 일괄 제어 | Part 노드 | 1 | 코어 |
| 그리기 순서 (0~1000, 파라미터로 변경 가능) | 앞뒤 순서 | 정수 순서 + 키폼으로 변경 | 1, 3 | 코어 |
| 텍스처 아틀라스 | 조각들을 한 장에 모은 그림 | 그대로 채택 | 1 | 저작 도구 |
| 파라미터 / 키 / 키폼 | 슬라이더, 슬라이더 위 기준점, 그 지점의 모양 | 다중 축 키폼 보간 | 2 | 코어 |
| 워프 디포머 | 격자로 휘게 하는 틀 (곡면 가능) | Warp 노드. 쌍선형 먼저, 베지어 나중 | 2, 5 | 코어 |
| 회전 디포머 | 회전·크기 조절 틀 | Rotate 노드 | 2 | 코어 |
| 디포머 중첩 | 틀 안에 틀 | 자유 중첩 | 2 | 코어 |
| 글루 | 두 메시 꼭짓점을 붙여 틈 방지 | Glue | 5 | 코어 |
| 블렌드 셰이프 (+가중치 제한) | 기본 모양에 차이를 더하는 방식 | Shape (가산) | 5 | 코어 |
| 클리핑 마스크 / 반전 마스크 | 다른 메시 안쪽(또는 바깥쪽)에만 그리기 | 마스크 텍스처 방식, 중첩·반전 | 3 | 렌더러 |
| 블렌드 방식 (메시별 합성 방법) | 일반·더하기·곱하기 등 | 블렌드 모드 | 3 | 렌더러 |
| 곱하기 색 / 스크린 색 | 메시 색조를 파라미터로 변경 | 셰이더 색 입력 | 3 | 렌더러 |
| 컬링 (뒷면 숨기기) | 뒤집힌 삼각형 안 그리기 | 메시 플래그 | 3 | 렌더러 |
| 물리 | 입력 파라미터 → 진자 → 출력 파라미터 | 진자 체인 | 4 | 코어 |

| 모션 (타임라인, 그래프 편집, 반복, 페이드) | 시간에 따른 파라미터 변화 | 모션 파일 + 재생기 | 4 | 애니메이션 |
| 표정 | 파라미터 묶음을 더하기·곱하기·덮어쓰기 | 표정 파일 | 4 | 애니메이션 |
| 포즈 (팔 A/B 전환) | 서로 배타적인 파트 전환 | 포즈 그룹 | 4 | 애니메이션 |
| 자동 눈 깜빡임, 숨쉬기, 시선 따라가기 | 대기 동작 | 내장 드라이버 | 4 | 애니메이션 |

| 랜덤 포즈 | 파라미터를 무작위로 흔들어 리깅 확인 | 뷰어 기능 | 2 | 저작 도구 |

## 3. 저작 도구 기능 (엔진이 아니라 편집 앱의 몫)

이 항목들은 엔진 기능이 아니라 편집 앱에서 만들 것들이다. 엔진은 이런 편집이 빠르게 반영되도록 "부분 갱신 API"만 제공하면 된다.

| Live2D 기능 | 우리 쪽 대응 | 단계 |
| --- | --- | --- |
| PSD 가져오기 | `ag-psd`로 레이어 → 메시 | 7 |
| 메시 자동 생성 / 수동 편집 | 윤곽 따기 + 삼각분할 (`earcut`/`delaunator`) | 7 |
| 디포머 자동 생성, 네 모서리 형태 자동 생성 | AI 자동 리깅의 핵심 후보 | 7 |
| 형태 붙여넣기, 디포머 형태 복원 | 편집 명령 | 7 |
| 3D 회전 표현 적용 (얼굴 각도 자동 생성) | 가장 가치 높은 자동화. AI 편집과 결합 | 7 |
| 흔들림·표정 모션 자동 생성 | AI 또는 절차적 생성 | 7 |
| 모델 템플릿 (리그를 다른 그림에 적용) | 리그 템플릿 | 7 |
| 어니언 스킨, 그리드, Shy, 멀티뷰 | 편집 UI 편의 기능 | 7 |
| 디포머 검증 | 모델 검증기 (AI가 쓰기 좋음) | 0~2 |
| 외부 API 연동 (에디터를 밖에서 조작) | 우리는 처음부터 AI용 조회·편집 API로 설계 | 7 |
| 영상·이미지 내보내기 | 헤드리스 렌더 | 6 |

## 4. 정리

- Live2D 런타임이 하는 일 중 우리 로드맵에서 빠진 것은 **아트패스** 하나다. 나머지는 모두 1~6단계에 들어 있다.
- Live2D의 진짜 강점은 엔진보다 **저작 도구의 자동화**(3절)에 있다. 우리 프로젝트의 원래 목표인 "AI가 편집하는 환경"이 바로 여기와 겹치므로, 엔진이 4단계쯤 오면 이 부분을 AI 기능으로 다시 설계하는 것이 차별점이 된다.
- 최근 Live2D 버전에서 화면 밖 그리기(오프스크린)와 블렌드 모드가 확장된 것으로 알고 있지만, 이번에 공개 설명서 목차에서 별도 페이지는 확인하지 못했다. 우리 엔진은 3단계에서 블렌드 모드를 화면 밖 버퍼 방식까지 포함해 설계한다.
