# 참고할 것과 라이선스

2026-11-02 기준. 라이선스는 npm·crates.io 메타데이터 또는 공식 페이지로 확인했고, 확인 못 한 것은 그렇게 적었다.

## 3. 알고리즘 참고 자료 (논문·공개 지식)

- 쌍선형·베지어 패치 보간: 컴퓨터 그래픽스 교과서 수준의 공개 수학.
- Free-Form Deformation (Sederberg & Parry, 1986): 격자로 공간을 휘는 기법의 원조.
- Position Based Dynamics (Müller 외, 2007), Verlet 적분: 진자·천 물리.
- Linear Blend Skinning, Dual Quaternion Skinning: 뼈대 변형.
- As-Rigid-As-Possible 변형 (Igarashi 외, 2005): 핀 몇 개로 그림을 자연스럽게 휘는 기법. 자동 리깅·AI 편집에 유용.

## 4. 법적 메모

- Live2D와 호환이 필요 없다는 결정(2026-10-04) 덕분에 비공개 `.moc3` 형식을 건드릴 일이 없다. 우리 형식은 처음부터 우리가 정의한다.
- "디포머", "키폼" 같은 개념 자체는 업계 공통이지만, 용어와 UI를 Live2D와 똑같이 베끼지는 않는 편이 안전하다. 이 문서들도 우리만의 용어(예: Warp, Rotate, Shape)를 쓴다.
- 이 분야 업체가 특허를 가지고 있는지는 이번에 확인하지 못했다. 상용 출시 전에 한 번 확인할 것을 권한다.
